### About the Experiment

This experiment covers the preparation and packing of a size exclusion (gel filtration) chromatography column and its use to separate a crude protein mixture.
The column is packed with cross-linked porous beads that swell in the mobile phase to form a three-dimensional mesh whose pore size decides which molecules can enter the matrix.
Large molecules are excluded from the pores and elute early, while smaller molecules enter the beads, travel a longer path and elute later, thereby separating the analytes by size.
Column parameters such as the void volume, pore volume, elution volume and the distribution coefficient (Kd) are determined from the resulting chromatogram.
